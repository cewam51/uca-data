# Règles relatives aux données

1. Toute visualisation doit référencer au moins une source.
2. Toute source utilisée doit être conservée avec sa version et son empreinte.
3. Toute transformation doit être reproductible.
4. Une jointure doit afficher son taux de correspondance.
5. Une différence de période doit générer un avertissement.
6. Une différence de granularité géographique doit être explicite.
7. Aucune donnée générée par IA ne peut être utilisée comme donnée factuelle.
8. Toute opération proposée par une IA doit devenir une recette déterministe et vérifiable.
9. Chaque graphique doit pouvoir être reconstruit à partir des données sources.
10. Les versions précédentes doivent rester accessibles.
